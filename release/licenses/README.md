# Release License Bundle Status

This directory is the runtime license bundle assembled for the controlled D2-R2 artifact.

The bundle contains exact texts/notices for SafePrompt, PaddleNLP-derived code, ONNX Runtime, NumPy,
Python, Qt/PySide/Shiboken, pynput, six, OpenSSL, pyreadline3 and PyInstaller. It is generated by
`release/assemble_license_bundle.py` from exact installed distributions and version-pinned official sources.

It does not license the UIE Nano weights, ONNX derivative, vocabulary or configuration assets. Those
assets remain BLOCKED pending positive written evidence. Microsoft runtime provenance is recorded by the
artifact inventory rather than by copying Microsoft terms into this directory. Legal review remains required.
